# Android 界面与交互验收清单

本文约束 TokenWorks Mobile 的 Android 表现层改造。清单不是已通过声明；实际构建、设备、操作、结果和未验证项应分别记录。现有协议、安全和各功能文档继续有效。

## 边界

- 保留 Kotlin、Jetpack Compose、Material 3、Hilt 和现有协调器；不另建网络、存储、导航授权或正文缓存拥有者。
- 不改后端、通信字段、scope、命令格式、请求 ID、分页、重连、签名、claim/release、数据库或保留政策。
- 只读展示状态不能恢复权限。同名电脑、工作区或会话不能合并资源身份。
- 不提供本机运行时、原生密码登录、全局未读、跨资源待处理、永久删除、扫码、语音或云分享的空入口。
- 不从目录存在推在线、不从块结束推成功、不从最近点击推当前模型。模型入口必须呈现真实能力及错误；现有目录 scope 的模型 action 透传缺口不在此次表现层改造中修复。

## 导航与布局

- [ ] READY 以授权目录和当前聊天为中心；会话抽屉、电脑管理、设置共享一个外壳，没有并行旧底栏。
- [ ] 目录搜索明确限定当前已取得目录；状态、工作区、最近访问只在当前授权范围内工作。
- [ ] 名称撤权立即回退碰撞安全标识；完整资源编号可从资料读取。
- [ ] 加载、错误、真正空目录、筛选无结果分别呈现；刷新期间保留的行不能操作，list-only 不提供正文读取。
- [ ] 打开或关闭抽屉、电脑面板、详情、改变窗口宽度本身不发读取或选择请求。
- [ ] 同一目录 LazyListState 同时只绑定一个列表；设置和电脑根不为侧栏后台取得目录。
- [ ] 高度不足 480dp 或宽度不足 600dp 保持单列；中等窗口用面板；展开级使用导航列和可选详情列。实际窗口分类不扣 IME，不使用物理屏幕替代多窗口。
- [ ] known-session 通知继续精确资源重授权，不因外壳索取广泛目录。
- [ ] 完整审批、问题表单、绑定和创建只有一个活动实例；隐藏背景不能保留表单、picker、分页或 receiver effects。
- [ ] 返回先处理键盘和当前层，再回原业务父页；关闭面板后焦点回到发起控件。

## 聊天与输入

- [ ] 助手正文无重复角色标题与重卡片，用户气泡自然收窄；角色仍有可访问语义。
- [ ] 只有相邻、纯过程、非错误、非中断且非空的消息组成过程组；正文、图片、用户、NOTICE、混合内容和错误打断分组。
- [ ] 摘要只称“过程”，不冒充任务完成、工具成功或真实回合；异常正文默认展开。
- [ ] 阅读位置始终保存原消息 ID 与 offset；前插历史、过程合并、收起展开和子页返回不把操作或位置绑定到另一个消息。
- [ ] 用户上翻停止追底；流式追加给出回最新入口；空 live 消息保留身份并说明正在准备回复。
- [ ] Markdown、代码、表格有界解析；局部横滚不撑宽页面；外链仍明确确认，不加载 HTML、远程图片或任意可执行资源。
- [ ] 复制与引用使用最新原文；只读背景没有复制、选择、链接、长按、预览、滚动及读屏动作。
- [ ] 紧凑/全屏共享一份 TextFieldValue、selection、composition、mode、revision；中文候选和 Enter 不发送。
- [ ] queue/steer 的含义和默认值保持；离线明确“保存待发送”，不会暗中转交或自动重放。
- [ ] 附件菜单仅选择具体文件、图库、拍照项才启动一次原系统回调；文件、图片资格独立判断。
- [ ] IME inset 只有一个拥有者；多行、长附件和两倍字号时主操作仍可达。
- [ ] 运行中停止仅在原 canCancel 成立时出现，继续使用 epoch-bound 确认；未明中断先核对原请求。
- [ ] 固定交付区区分本机保存、中继收到、电脑保存、Agent 排队、settled 和 outcome_unknown，不重复同一错误。
- [ ] 当前待处理计数与定位不 claim；显式打开计时表单才按原 handle claim，关闭 release。
- [ ] 提交期间继续编辑、迟到保存、失败恢复不会清空或覆盖新草稿。草稿只按既有容量和前台资源政策保留。

## 业务页面

| 页面 | 必须保留的验收边界 |
| --- | --- |
| 登录与设备登记 | 区分受控 OIDC、开发身份和网页账号；配置缺失/错误、恢复失败、忙碌、登记未知各自可解释；不把网页 Cookie 当远控授权 |
| 电脑绑定 | 完整 UUID、绑定码、双端指纹核对、未知结果查询和后台退役；名称不能代替身份 |
| 显式创建 | 工作区/配置选择、原请求未知核对、结果打开；不改成发送时懒创建 |
| 完整审批 | 所有字段、未知字段和尾页完整可达；独立 consent；拒绝始终可达；allow_once/reject 和逐次强生物识别不变 |
| 问题 | 原问题、计划、必答、claim/release 和原答案核对；答案与勾选不持久化 |
| 文件与图片 | 扫描通过、电脑暂存、消息关联是不同阶段；下载和预览独立授权；取消、迟到 URI、回读保存、撤权清理仍有效 |
| 模型 | 分页、部分 provider 失败、DENIED、旧 context 和未明原请求分别呈现；不默认选择，不产生新请求替代未明原请求 |
| 差异 | 只读工作区快照、HEAD/版本、partial/binary/stale 提示；只有 completePatch 可完整复制，不执行补丁 |
| 消息操作 | fresh anchor 确认、授权文本 ACTION_SEND、分支原请求与已核实结果；不新增云链接或全历史导出 |
| 通知 | 通道状态和引用列表分层；引用不是授权或完整索引，不含正文，不快捷批准 |
| 更新 | 显式下载源、字节/签名/发布/系统安装会话核对不变；未知或不可用不能伪造进度 |
| 外观 | 原四标量、0.8–1.6 范围和 owner 隔离；系统字号叠加，保存失败可重试，退出/后台策略不变 |
| 设置与退出 | 完整账号/设备身份渐进展开；退出独立确认；清本机登录不称删除远端会话 |

## 状态所有权与安全

阅读位置与导航提示只保留于当前身份的展示内存。审批 consent、答案、claim、签名、URI/grant、正文和凭据不能放入 rememberSaveable 或普通偏好。账号、部署、设备、资源、epoch/sync、handle 或前后台变更时，以原控制器退役为准。模型/diff 等路由需要聊天背景时，只渲染当前授权 window 的无动作正文，不持续挂载原活动聊天。

## 设备、可访问性与证据

- 覆盖 320/360dp 手机、短横屏、600/840/1280dp 窗口、临界宽度连续变化、明暗主题、默认及两倍字号、真实键盘与系统选择器。
- 图标操作至少 48dp；文字对比度至少 4.5:1，关键控件至少 3:1；错误、禁用、连接与折叠不只靠颜色表达。
- 实际验证 Tab/方向键、模态焦点隔离、关闭焦点恢复、长名称和代码横滚。TalkBack 未安装或未执行必须明确报告，不能以 semantics 断言替代人工读屏。
- 正式 MainActivity 保持 FLAG_SECURE。截图仅来自非 secure 的公开合成宿主，不捕获真实会话或凭据。
- JVM、编译、设备交互、控制器 TLS 场景、既有真实服务、物理设备与生产身份分别报告。assume/跳过不是通过，旧结果不能记成本轮执行。
- 性能采用相同公开输入和设备记录帧、卡顿与内存；没有改前测量不宣称提升。软件模拟器 debug 数据不等于物理 60Hz 发布性能。
- 不为测试重置 PIN、登记新指纹、清真实账号、改变全局字号/密度、重启已有服务或扩大权限。
