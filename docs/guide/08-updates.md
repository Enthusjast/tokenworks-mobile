# 应用更新

[用量](07-usage.md) · [故障排查](03-troubleshooting.md)

## 场景：收到部署方的新版本通知

1. 登录后打开 **设置 → 应用更新**，检查当前设备适用的版本。若显示未配置或暂无适用版本，请联系部署方；不要从聊天或二维码里的陌生地址安装 APK。
2. 选中版本并启动下载。Android 若要求允许本应用作为安装来源，先核对系统页中的应用；返回后仍需明确发起下载或安装。下载期间可以取消。
3. 等待应用校验完整文件、版本和签名，再打开系统安装确认。安装完成后回到应用核对实际版本。看到“结果未知”时先核对，不重复提交安装。

更新不会静默安装或降级。组织可能分批发布，因此同事能看到更新不代表当前设备也已获准。若发布被撤销、账号变更或签名不匹配，停止安装并重新检查。
