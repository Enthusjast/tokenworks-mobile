# 审批、提问与签名

[会话](02-sessions.md) · [文件](05-files.md) · [安全说明](../../SECURITY.md)

## 场景：电脑发来一次工具审批

1. 打开正确的电脑和会话。查看卡片里的工具和请求理由；涉及跨主机动作时，核对源和目标。信息不足时，打开电脑端查看完整上下文，不要盲目点允许。
2. 选择允许或拒绝。允许一次只回答这一条请求。若部署要求签名确认，先核对明确显示的请求，再完成系统验证；取消验证不会变成批准。
3. 在会话中确认实际结果。按钮消失只表示卡片不再可回答，不表示命令一定执行了。断线后先重新读取当前状态，不重复批准旧请求。

账号、设备证明与 Noise 连接会验证回答者身份；原生审批卡片不是一份可跨会话重用的签名。只有当前授权允许回答的 owner 可提交决定。看见会话或收到通知不代表拥有审批权。已撤销的请求不能通过切换网络重新批准。

普通提问与工具审批不同。按问题要求选择选项或填写答案后明确提交；定时问题是否接受补答由电脑决定。不要把补答发送成普通聊天来冒充原问题的回答。
