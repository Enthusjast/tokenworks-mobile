# 远程终端

[文件](05-files.md) · [用量](07-usage.md)

## 场景：查看当前工作目录

1. 核对聊天页上的电脑及会话，再从会话菜单进入 **远程终端**。
2. 选择已有终端，或选择一个电脑提供的 shell 创建终端。连接后可输入 `pwd`（POSIX shell）核对目录，再决定是否继续。
3. 只想离开终端页时按返回。如果要结束进程，使用终端的关闭操作并核对列表；退出页面、网络断开或输出停止都不等于进程退出。

终端命令以电脑侧被授权的身份执行，可能修改文件或产生外部副作用。断线恢复后不会重发历史输入。会话能读但终端入口不可用时，请检查电脑运行时与终端授权，不能通过另一条网络路径绕过权限。
