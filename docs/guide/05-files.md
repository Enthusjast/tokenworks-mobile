# 文件、附件与分享

[审批](04-approvals.md) · [终端](06-terminal.md) · [隐私与数据](../../PRIVACY.md)

## 场景：在手机上保存电脑生成的报告

1. 从已加入工作区的会话打开右上角菜单，进入 **文件与附件 → 工作区**。这里只读，不会在电脑上创建、重命名或删除文件。
2. 打开报告所在目录，选择 **加入导出列表**，在 **导出 → 保存到手机…** 选择系统文件目标。单个文件最多 200 MB，可取消保存；应用会尝试删除未完成的目标。如果原文件在下载期间变化，刷新目录后重新加入导出列表，不要拼接两次下载结果。
3. 如果要带走的是对话而非工作区文件，从会话菜单打开 **分享或导出会话**，可保存 JSONL 或 Markdown。导出读取当前授权下的历史快照，需要连接电脑，不会用离线缓存冒充完整记录。

浏览以电脑登记的工作区为边界，不跟随符号链接或导出多重硬链接；不支持该安全文件接口的电脑会拒绝浏览，而不会降级到任意路径读取。输入栏的 **+ → 文件引用** 只把路径文字插入草稿，不上传文件。需要传送实际附件时，在文件与附件页用系统选择器挑选，再明确发送。

若组织启用了分享，可生成有期限的只读链接并显示二维码。链接及二维码都包含解密所需的秘密；只发给你想授权的人。接收者可以保留副本，过期不能删除对方已经保存的内容。导出的本地文件也不再受应用私有存储保护。
