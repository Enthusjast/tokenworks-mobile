# Token 用量与费用估算

[终端](06-terminal.md) · [更新](08-updates.md)

## 场景：对比当前电脑上两个模型的用量

1. 选择电脑，在 **设置 → 用量** 打开统计。切换会话、模型或日期视图；日期按设备本地时区显示。
2. 打开 **费用表**，按提供方和模型录入每百万 Token 的美元价格，只填写有可靠报价的类别。改价会更新本机估算，不修改电脑或提供方数据。
3. 返回用量页。没有已知模型、日期或价格的数据不会被猜测为零；按模型或日期需要已观察到的明细，不能把只有会话累计值的历史强行分摊。

<!-- 截图位置：按模型的用量列表、未定价提示与费用表入口。 -->

用量是当前授权范围内电脑报告的统计，不是发票。费率、套餐、缓存折扣及模型提供方的计费口径可能不同，核账以提供方账单为准。
